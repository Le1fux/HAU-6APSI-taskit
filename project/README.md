## What it is
TaskIt is a study app. A student uploads a PDF of their notes, the app
reads the text, and it builds a summary and a practice quiz with a score
and a list of missed questions.

## How to run it

1. Clone the project repository and install dependencies: `npm --prefix client install` and `npm --prefix server install`.
2. Copy `.env.example` to `.env` in the repo root. The API key is optional; demo mode builds the reviewer locally from the PDF text.
3. Start the server from the `server` folder with `npm run dev` (optional in demo mode), and the client with `npm --prefix client run dev`.
4. Open [http://localhost:5173](http://localhost:5173/) and upload a text-based PDF.
